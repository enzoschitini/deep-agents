# Formato do relatório

- Comece com um resumo de 2 a 4 frases que responda à pergunta direto.
- Depois, organize o desenvolvimento em seções curtas com títulos claros.
- Termine com uma lista "Fontes" contendo título e URL de cada fonte usada.
- Use tabelas só para comparar itens com os mesmos critérios.
- Mantenha um tom objetivo e profissional, sem enrolação.
